# psa-prep

Outil local qui transforme une pile de cartes scannées (One Piece, Pokémon — FR, EN, JP) en submission PSA prête : la référence exacte à saisir pour chaque carte, puis (phase 2) le formulaire pré-rempli via une extension Chrome.

La source de vérité du projet est [SPEC.md](SPEC.md) (cahier des charges). Le document Word d'origine est dans [docs/](docs/).
